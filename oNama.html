O kursu

Kurs je namenjen onima koji su zainteresovani za razvoj i klijentske i serverske strane web aplikacija. Naš kurs će Vam pružiti znanja o osnovama jezika JavaScript, njegovim mogućnostima za objektno programiranje, njegovim mogućnostima za funkcionalno programiranje i upoznaće Vas sa načinom na koji se integrišu JavaScript i HTML.

Tehnologije koje smo koristili:
  • JavaScript
  • Bootstrap 5
  • CSS
  • HTML 5
  • Font Awesome
